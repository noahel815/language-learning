# English Codeword

數字填字遊戲（英文）。網址：https://noahel815.github.io/language-learning/english/

- 內容在 `puzzles.js`（純 JSON 陣列）；遊戲頁 `index.html` 不需改動。
- 庫存上限 10 題；超過時刪掉最舊且已玩過的題。
- 檢查：`python3 english/validate_puzzles.py`

## 出題規則（每次出題前必讀，另見根目錄 CLAUDE.md）
- 流程：玩家貼回「成績」後，依成績出**下兩題**。成績含提示次數、填錯次數、用時。
- 難度：`一般` 的提示字全部由句子內的字母組成；`偏難` 至少有 3 個只出現在提示字的字母，且句子更長、字更難。依成績調整兩種的比例：提示少、填錯少、用時短 → 多出偏難；反之多出一般。
- 題材：生動活潑、跟進時事（台灣、日本、科技與 AI、商管、生活）。句子一律原創，輕鬆口吻，不抄新聞標題與引言、不用歌詞或電影台詞；避開政治爭議、災難與悲劇。時事資訊要先查證再寫進 `note`。
- 不放：工作、職場、客戶情境；任何金額、公司名、學校名、姓名、信箱、路徑。
- 每題：6 個以內提示字，每個提示字要附英文提示與中文意思；`quoteZh` 與 `note` 用台灣用語。
